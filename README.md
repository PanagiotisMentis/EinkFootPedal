# EinkFootPedal
Schematics and PCB designs for a 4-layer ESP32-based Bluetooth capacative touch board. 

> [!NOTE]
> *This project is still in progress, but the initial schematics and layout are included below.

## Features
* 3.3V Buck boost regulator using a TP63020 IC
* LiPo Charger with indicators using a BQ24090 IC
* USB-C-2.0 interface for programming and power
* GPIO headers for alternative uses
